# **App Name**: VirtuLink

## Core Features:

- Product Catalog & Search: Browse virtual numbers, eSIMs, and VPN subscriptions with an integrated search bar for easy filtering.
- User Accounts & Management: Customers can register, log in, manage their profile details, and review personal settings.
- Order Placement & Bank Payment Details: Users can add digital products to an order, view a summary, and receive clear instructions including bank account details and the exact amount for payment.
- Payment Proof Upload: After initiating a bank transfer, customers can upload a payment screenshot to submit their order for review.
- Admin Dashboard & Order Management: A secure administrative interface for reviewing submitted orders, verifying payment proofs, updating order statuses (Pending, Paid, Completed), and managing product listings (add/edit/remove).
- AI-Powered Product Description Tool: An administrative tool that leverages generative AI to create compelling and concise product descriptions for new virtual numbers, eSIMs, and VPN services.
- Customer Dashboard & WhatsApp Support: A personalized dashboard for customers to view their order history and current statuses, alongside a dedicated WhatsApp support button for direct assistance.

## Style Guidelines:

- Primary color: A sophisticated, trustworthy deep blue (#1F4EAD) to convey reliability and professionalism, contrasting sharply with the light background.
- Background color: A very subtle, cool-toned off-white (#F0F2F4) to ensure a clean, professional, and easy-to-read user experience, keeping focus on digital products.
- Accent color: A vibrant, clear cyan (#1FC7F2) to highlight key actions and interactive elements, providing an energetic and modern touch while maintaining an analogous relationship with the primary blue.
- Body and headline font: 'Inter', a grotesque-style sans-serif for its modern, machined, and neutral aesthetic, ensuring excellent readability and a contemporary feel across all content.
- Use a set of clean, minimalist line icons that represent digital services, connectivity, and administrative actions, maintaining a consistent professional aesthetic.
- Implement a clean, spacious, and fully responsive layout designed with a mobile-first approach. Utilize card-based designs for product listings and clearly segmented sections for account management and admin panels.
- Incorporate subtle hover animations on interactive elements and smooth transition effects for page changes and order status updates to enhance user feedback and overall polish.
